# Document Clustering App

This is a simple Gradio app that clusters sentences from a CSV into categories like politics, sports, entertainment, and technology.  
- Upload a CSV with a `sentence` column.
- The app shows clusters and a t-SNE visualization.

### How to run
pip install -r requirements.txt
python app.py 


And you can also try it online:
https://huggingface.co/spaces/deorakuldeep/document_clustering
